# Анимация приветствия

В проект включён пользовательский оригинал `welcome.gif`: 720×406, 75 кадров,
5 секунд, около 4,8 MB. После `/start` бот отправляет эту анимацию,
приветственный текст и кнопки одним сообщением.

Чтобы заменить её, положите сюда другой оригинальный GIF с именем `welcome.gif`.

Можно использовать MP4 без звука, указав в `.env`:

```text
WELCOME_ANIMATION_PATH=assets/welcome.mp4
```

Рекомендуемый размер — несколько мегабайт. Максимум ограничен `MAX_UPLOAD_MB`
и 50 MB. Файл попадает в Docker-образ при сборке; после замены пересоберите образ
и пересоздайте bot. Первая отправка загружает файл, следующие используют `file_id`
из Redis. Замена содержимого анимации автоматически создаёт новый ключ кэша.

Если файла нет или Telegram отклонил анимацию, остаётся текстовое приветствие.
