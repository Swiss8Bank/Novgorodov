# LUMA — загрузчик видео с YouTube

[Скачать LUMA.zip](./LUMA.zip)

Распакуйте архив и запустите `START.bat` на Windows 10/11 x64.
При первом запуске автоматически устанавливаются Python, FFmpeg, Deno
и библиотеки. Для установки необходим интернет.

Интерфейс: темная тема, зеленый акцент, выбор качества и папки.
Поддерживаются cookies из Chrome/Firefox/Edge или файла, системный VPN
и отдельный HTTP/SOCKS-прокси. По умолчанию — до 1080p и 8 фрагментов.

Инструкция и границы проверки находятся внутри архива в README.txt
и VALIDATION.txt. Запуск Windows и загрузка непосредственно с YouTube
не проверялись в сборочной среде; проверены интерфейс и 19 тестов.
