# LUMA 1.2 — загрузчик видео с YouTube

[Скачать LUMA.zip](./LUMA.zip)

Распакуйте архив в новую папку и запустите START.bat.

Версия 1.2: настройка подключения для Windows, системного VPN/TUN
и отдельного HTTP/SOCKS-прокси. Для VPN, работающего в режиме TUN
на всем компьютере, выберите «VPN / TUN — без прокси» в настройках доступа.
Если нужен HTTP/SOCKS-прокси, скопируйте полный адрес из VPN-приложения.
Адрес 150.241.69 неполный для IPv4: нужны четыре группы цифр.

Сохранены исправления установки Tcl/Tk из версии 1.1.
Инструкции и границы проверки: README.txt и VALIDATION.txt внутри архива.
