# LUMA 1.1 — загрузчик видео с YouTube

[Скачать исправленную LUMA.zip](./LUMA.zip)

Распакуйте весь архив в новую папку и запустите `START.bat`.

В версии 1.1 исправлена проверка Tcl/Tk в Windows PowerShell:
строки Python с кавычками заменены отдельным файлом bootstrap_probe.py.
При реальном отсутствии Tcl/Tk установщик подбирает рабочий Python или
добавляет компонент через проверенный официальный установщик Python 3.13.
`REPAIR.bat` запускает восстановление принудительно.

Подробные инструкции — в README.txt внутри архива. При первом запуске
нужен интернет; Python, FFmpeg, Deno и библиотеки устанавливаются автоматически.
Скачивание с YouTube и установка Windows в сборочной Linux-среде не
проверялись; проверены GUI, загрузчик, диагностика и сценарий PowerShell.
